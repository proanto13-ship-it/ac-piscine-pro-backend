# Pricing

## Positionnement simple

Le produit repose sur deux niveaux simples :

- `Free`
- `Pro`

Un essai gratuit peut etre propose si l'environnement backend l'active.

## Free

Le plan `Free` convient pour decouvrir le produit et demarrer une petite utilisation locale.

Inclus :

- gestion locale des clients, analyses et interventions
- stockage local sur l'appareil
- onboarding, checklist et mode demo
- export local des donnees
- support via export de diagnostic

Limites principales :

- nombre de clients limite
- pas d'export PDF Pro
- pas de synchronisation cloud
- pas de gestion d'equipe

## Pro

Le plan `Pro` debloque les fonctions commerciales et collaboratives.

Inclus au minimum :

- clients illimites
- export et partage PDF
- synchronisation cloud
- gestion d'equipe

Selon la configuration backend, `Pro` peut aussi s'appuyer sur :

- invitations d'equipe
- partage public en lecture seule de certains rapports
- cycle de vie d'abonnement complet (`trial`, `active`, `past_due`, `canceled`, `expired`)

## Remarque honnete

Le produit ne doit pas afficher de promesse de paiement automatise ou de facturation SaaS si l'environnement de lancement ne l'active pas effectivement. Le mode mock/dev existe encore et doit rester reserve aux environnements de test.

## Message court pour le site

`Free` pour demarrer en local. `Pro` pour vendre, partager, synchroniser et travailler en equipe.
