# App Store / Play Store Copy

## Titre court

HydrAzur - Gestion piscine pro

## Sous-titre / accroche courte

Clients, interventions, photos, PDF et sync cloud pour professionnels piscine.

## Description courte

HydrAzur aide les pros piscine a suivre leurs clients, enregistrer leurs interventions, ajouter des photos, generer des PDF et synchroniser leurs donnees.

## Description longue

HydrAzur est une application de terrain pour les professionnels piscine.

Elle permet de :

- gerer un portefeuille clients
- enregistrer des analyses et interventions
- ajouter des photos sur chantier
- generer des PDF de diagnostic, intervention et documents financiers
- partager certains rapports
- synchroniser les donnees avec un backend compatible

L'application fonctionne d'abord en local pour rester utile sur le terrain, meme avec une connexion instable.

Selon votre configuration et votre abonnement, vous pouvez aussi debloquer :

- export et partage PDF
- synchronisation cloud
- gestion d'equipe
- clients illimites

Fonctions utiles :

- mode demo pour les presentations
- checklist d'onboarding
- export des donnees locales
- suppression locale et demande de suppression de compte backend
- support integre avec export de diagnostic non sensible

## Points forts

- pensee pour le terrain
- utilisable en local
- photos et rapports PDF
- synchronisation V2 avec isolation par organisation
- support de l'equipe et des roles simples

## Notes honnetes pour la fiche store

- certaines fonctions dependent de la configuration backend
- les fonctions Pro dependent des entitlements et du statut d'abonnement
- le partage public est en lecture seule et limite aux ressources autorisees
