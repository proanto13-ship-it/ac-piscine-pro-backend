# FAQ

## A quoi sert l'application ?

L'application aide un professionnel piscine a :

- gerer ses clients
- enregistrer des analyses et interventions
- ajouter des photos de chantier
- generer des PDF de diagnostic, intervention et documents financiers
- synchroniser les donnees avec un backend V2 si la synchronisation cloud est activee

## L'application fonctionne-t-elle hors ligne ?

Oui. Les donnees principales sont conservees localement sur l'appareil. La synchronisation cloud est optionnelle et depend de votre configuration.

## Puis-je partager un rapport avec mon client ?

Oui. L'application peut generer des PDF partageables et, si le backend V2 est configure, creer des liens publics en lecture seule pour certains rapports et interventions.

## Les photos sont-elles prises en charge ?

Oui. Les interventions peuvent contenir des photos. En mode local, elles restent sur l'appareil. Avec la synchronisation V2, les medias peuvent etre televerses vers le backend configure.

## Puis-je utiliser l'application a plusieurs ?

Oui, avec l'offre Pro et un backend V2 configure. L'organisation peut gerer plusieurs membres avec des roles simples : `admin`, `manager`, `technician`.

## Quelles fonctions sont reservees au plan Pro ?

Au minimum :

- export et partage PDF
- synchronisation cloud
- gestion d'equipe
- clients illimites

## Existe-t-il un essai gratuit ?

Oui si l'essai est active dans la configuration du backend. Selon le contexte, l'utilisateur peut voir un statut `trial`, `active`, `past_due`, `canceled` ou `expired`.

## Que se passe-t-il si l'abonnement expire ?

L'application garde vos donnees locales, mais les fonctions Pro peuvent etre bloquees selon le statut de l'abonnement.

## Puis-je exporter mes donnees ?

Oui. L'application permet d'exporter les donnees locales en JSON. Avec une session backend V2 active, un export backend peut aussi etre demande.

## Puis-je supprimer mes donnees ?

Oui. L'application permet :

- la reinitialisation des donnees locales
- la suppression du compte backend si la session V2 est active et si le backend le permet

## Comment obtenir de l'aide ?

Depuis l'ecran `Aide / Support`, vous pouvez :

- signaler un bug
- envoyer un retour
- exporter un diagnostic technique non sensible exploitable par le support
